# Ours：Seal 测试预测与统一评估

## 数据与预测

- 预测来源：项目根目录 `Ours/test_maps.zip`，解压至 `Ours/test_maps/`，共 1,983 张 8 位灰度 PNG。
- GT 来源：根目录 `Seal.zip` 中的 `Seal/test/GT/`，提取至 `Ours/Seal_test_GT/`。
- 预测与 GT 的 1,983 个文件名完全对应，所有图像尺寸均为 417×622，无尺寸不匹配，无空 GT。
- 表格将 Ours 标为 RGB-T、Box。本次使用已有预测进行评估，不重新训练或推理。
- 评估日期：2026-11-03。四项指标直接调用 `Ours/evaluate.py` 的四个固定原函数计算，每个函数均评估 1,983 对预测与 GT。E 为原函数对连续灰度预测计算的结果。

## 统一评估结果

| 结果来源 | S↑ | Fw↑ | E↑ | MAE↓ |
|---|---:|---:|---:|---:|
| 指定四个原函数，最终比较口径 | 0.49915 | 0.67338 | 0.66731 | 0.00015 |
| 腾讯表格原有记录 | 0.49781 | 0.51296 | 0.64987 | 0.00055 |
| 其他评估口径，存档 | 0.80498 | 0.67439 | 0.94830 | 0.00015 |

量化 SOTA 表采用指定四个原函数的完整结果，不根据数值大小混用不同口径。完整精度指标见 [`Ours/unified_metrics.json`](../Ours/unified_metrics.json)；其他口径结果保存在 [`Ours/other_protocol_metrics.json`](../Ours/other_protocol_metrics.json)。

根目录 `evaluate.py` 的四个指标函数与 `Ours/evaluate.py` 原文一致，入口额外接收 GT 路径。两种评估口径在 S 的区域计算、Fw 的高斯平滑及 E 的计算方式上不同，MAE 的实现相同。

在项目根目录复算：

```bash
python evaluate.py \
  --pred_root Ours/test_maps \
  --gt_dir Ours/Seal_test_GT
```

## 预测分析

面积占比为逐图计算后平均；precision 和 recall 同时列出逐图平均与汇总全部像素后的结果。阈值统计使用灰度值大于 128 的像素，不用于替代连续灰度预测的 Fw 或 MAE。

| 项目 | 结果 |
|---|---:|
| GT 平均前景面积占比 | 0.020553% |
| 预测平均前景面积占比，阈值 128 | 0.018883% |
| precision，逐图平均 | 65.53% |
| recall，逐图平均 | 60.62% |
| precision，汇总全部像素 | 64.64% |
| recall，汇总全部像素 | 59.39% |
| 阈值以上无预测前景的图像 | 19 / 1,983 |
| 预测中灰度值为 0 的像素占比 | 99.975767% |
| 预测中灰度值为 1～254 的像素占比 | 0.019607% |

完整统计见 [`Ours/prediction_analysis.json`](../Ours/prediction_analysis.json)。Ours 的预测区域规模接近 GT，背景响应稀疏。对比方法在 Seal 上的大量背景误检会同时拉低 Fw、抬高 MAE；这解释了统一评估后仍存在的量级差异。

Seal GT 的平均前景面积占比为 0.00020553，因此全黑预测的平均 MAE 也为 0.00020553。Ours 的实际 MAE 为 0.00015090，低于该全背景基线，并具有 0.67338 的 Fw。

## RGB 与热图可视化

服务器归档：`/share_datasets/Seal_Model_Reproduction/Ours/vis.zip`，压缩包为 1,050,737,442 字节。大文件仅保留服务器副本。

| 目录 | 数量 | 内容 |
|---|---:|---|
| `vis/RGB/` | 3,983 | RGB 场景可视化，样例带框与类别标记 |
| `vis/T/` | 3,983 | 热图可视化，样例带框与类别标记 |
| `vis/T0/` | 3,983 | 热图可视化，样例不带框与类别标记 |

三组均为 JPG，编号覆盖 1～3,983，包含完整测试编号 2,001～3,983。它们可用于核对两路图像的目标位置、检查微小目标的可见性，并结合 GT 和预测图展示误检、漏检。样本 2001 的图像尺寸为 417×622，GT 包围框为 4×8 像素。

本地保留该样本的三张小图：[RGB](../Ours/vis_samples/2001_RGB.jpg)、[T](../Ours/vis_samples/2001_T.jpg)、[T0](../Ours/vis_samples/2001_T0.jpg)。

这些导出的 JPG 用于展示，不替代原始 16 位热图、框坐标或二值 GT。压缩包未提供 T/T0 的转换代码，不能仅凭显示效果确定其数值变换方式。

## 已知问题

- 压缩包未附对应训练检查点、训练配置或推理命令；本记录确认的是这批预测图在 Seal 测试 GT 上的指标。
- 使用指定原函数后，结果仍未完全复现腾讯表格旧值。两种口径的 MAE 实现相同，均得到 0.00015090；原表 MAE 0.00055 的差异不能由此次公式切换解释。原表未附预测、GT 路径及评估日志，具体输入差异尚不能确定。
