# 小目标评价指标：定义与代码对照

本项目使用根目录 `metrics.py` 中的 `AS1000Metrics` 统一计算 IoU、F1、Pd、Fa，命令行入口为 `evaluate_small_targets.py`。该类名是项目接口名，采用下述已发表论文官方代码中的像素累计及传统质心匹配口径。核对日期：2026-11-03。

## 代码实现对照

| 项目 | MSHNet | PAL | PyIRSTDMetrics | 本项目采用 |
|---|---|---|---|---|
| 像素 IoU | 累计交集、并集 | 累计 IoU 与逐图 nIoU 分开 | 提供 sample-based 和 whole-based | 全数据集累计 IoU |
| 像素 F1 | ROC 类可计算 precision/recall |该脚本不直接输出 F1 | FmeasureHandler，beta=1 | 全数据集累计 F1，beta=1 |
| 连通域 | 8 连通 | 8 连通 | 8 连通 | 默认 8 连通 |
| Pd 匹配 | 质心距离严格小于 3；匹配后删除预测 | 同左 | ProbabilityDetectionAndFalseAlarmRate / DistanceOnlyMatching：逐 GT 匹配首个可用预测 | 栅格扫描顺序，一对一，距离严格小于 3 像素 |
| Fa 分子 | 按面积值排除已匹配面积 | 预测总面积减已匹配总面积 | 按未匹配连通域身份累计面积 | 按未匹配连通域身份累计面积 |
| Fa 分母 | 固定图像尺寸×图像数 | 实际总像素数 | 实际总像素数 | 原尺寸图像实际总像素数 |
| 固定阈值 | 同时提供多阈值路径 | PNG >127 | 单阈值概率 >0.5 | 概率 >0.5，即 8 位 PNG ≥128 |

MSHNet 的 `PD_FA` 采用按面积值过滤的方式：若未匹配预测与已匹配预测面积相同，会漏计该未匹配区域。本项目按组件身份统计，保持 PAL 与 PyIRSTDMetrics 的计数语义。方形固定尺寸不作为本项目数据前提。

## 固定评估协议

在预测恢复到 GT 原尺寸、按项目既有推理流程保存灰度 PNG 后评估。读取预测除以 255；GT 使用 `>128` 二值化。不额外执行 sigmoid、逐图归一化、形态学处理或面积筛选。

预测按 `prob > 0.5` 二值化。每张图独立提取 8 连通域，质心使用该连通域像素坐标的均值。按栅格顺序依次遍历 GT 连通域，每个 GT 匹配首个尚未使用、欧氏质心距离严格小于 3 像素的预测连通域。一个 GT 与一个预测最多匹配一次。

令 TP、FP、FN 为全数据集累计的像素计数，N_gt 为 GT 连通域总数，N_detected 为匹配成功的目标总数，A_unmatched 为未匹配预测连通域总面积，N_pixels 为全部图像总像素数：

```text
IoU = TP / (TP + FP + FN)
F1  = 2TP / (2TP + FP + FN)
Pd  = N_detected / N_gt
Fa  = A_unmatched / N_pixels
```

所有结果均输出 0～1 原始比例。分母为零时返回 0，与 PyIRSTDMetrics 的安全除法约定一致。汇总表保存原始比例；文献常用的 Fa(10^-6) 显示值等于原始 Fa×10^6，必须注明单位后才能比较。

IoU、F1、Pd 越高越好，Fa 越低越好。四项新指标使用同行 S、Fw、E、MAE 对应的同一检查点及预测目录，不根据测试集重新选择阈值或权重。

## 使用方法

```bash
python evaluate_small_targets.py \
  --pred_root <预测PNG目录> \
  --gt_dir /share_datasets/Seal_Model_Reproduction/Seal_data/test/GT \
  --json_output <输出JSON路径>
```

入口核对完整 PNG 配对与原尺寸一致性，输出完整精度指标、像素/目标计数、输入路径及协议参数。它独立于 `Ours/evaluate.py` 的四个固定原函数。

本地验证命令：

```bash
python -m unittest discover -s tests -p test_small_target_metrics.py -v
```

验证覆盖完美/全漏检、等面积误检、严格 3 像素边界、一个预测靠近多个 GT、对角连通、跨不同尺寸图像的累计、纯背景图与固定二值化阈值。

## 已知问题

- `docs/小目标评价指标.pdf` 给出指标名称及类初始化参数，未包含完整更新、匹配和输出代码。本项目的具体实现由上述公开代码对照确定。
- 传统 Fa 计入未匹配预测区域的面积；已匹配预测区域超出 GT 的部分由 IoU、F1 反映。它与像素 FPR=FP/(FP+TN) 的分子和分母均不同。
- Pd 允许 3 像素内的定位偏移，即使预测与 GT 没有交集也可能匹配。Pd 应与 IoU、F1、Fa 联合报告。
