# Seal 全监督 IRSTD 基线评估汇总

全监督红外小目标检测方法在 Seal 上从零训练（Seal train 1,500 张全像素 GT）、在 Seal test（1,983 张）测试的统一结果。第一批（2022–2024 老方法）见下一节，第二批按年份要求补充 2024 / 2025 / 2026 方法。

## 协议要点

| 项目 | 说明 |
|---|---|
| 输入 | Seal 热红外 `T`：16 位 TIFF 逐图 min-max → 8 位 → 单通道或 3 通道（`Seal_IRSTD/`） |
| 训练 | Seal train，crop 256×256，官方优化器/损失/学习率日程（各方法 epoch 见记录） |
| 选择 | Seal val 500 张滑窗像素 IoU@0.5 最优；test 不参与任何选择 |
| 推理 | 原生分辨率 256×256 滑窗、步长 128，重叠 logits 平均后 sigmoid → 8 位 PNG |
| 四项指标 | 根目录 `evaluate.py` 四个原函数（S / Fw / E / MAE），同一批 1,983 张预测 |
| 小目标四项 | 根目录 `metrics.py` 的 `AS1000Metrics` + `evaluate_small_targets.py`（IoU / F1 / Pd / Fa，原始比例） |

## 平凡基线：全背景预测

为判断上表各列是否真的在区分方法，用同一批 1,983 张 test GT、同一条 `evaluate.py` 计算"全部预测为背景"（1,983 张全零 PNG）的平凡基线。本地 `Ours/Seal_test_GT` 与服务器 test GT 一致：用同一脚本复算 Ours 得到 S 0.4991494322239128、Fw 0.6733816023670935、E 0.6673133063380616、MAE 0.00015089529912774，与表中 Ours 行逐位相同。

| 来源 | S↑ | Fw↑ | E↑ | MAE↓ | IoU↑ | F1↑ | Pd↑ | Fa↓ |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| 全背景预测（平凡基线） | 0.49990 | 0 | 0.25 | 0.00020553 | 0 | 0 | 0 | 0 |

结论（只影响读表方式，不改任何表值）：

- **S 在本数据上几乎不区分方法**。八个全监督基线的 S 为 0.49799–0.49902，Ours 为 0.49915，全部低于全背景基线的 0.49990。Seal 的 GT 前景仅占 0.0206%，S 的 object/region 两项都被背景主导，预测出的少量前景反而略微拉低 S。S 的 0.001 量级差异不能当作方法优劣。
- **MAE 同样被背景主导**。八个基线的 MAE（0.000229–0.000375）全部高于全背景基线的 0.00020553，即"什么都不预测"的 MAE 更好；只有 Ours（0.00015090）低于该基线。故 MAE 只在"是否优于平凡解"这一层有意义。
- **区分力在 Fw / IoU / F1 / Pd / Fa**。Fw 从平凡解 0 升到 0.27–0.54（基线）与 0.673（Ours）；E 从 0.25 升到 0.664–0.686；IoU/F1/Pd 与 Fa 直接反映目标级检出与误检。跨行比较应以上述五列为主，S/MAE 与平凡基线并列给出。
- **IoU 需读数于边界尺度**：Seal 目标平均 14.3 像素，把 GT 膨胀/腐蚀 1 像素只能得到 IoU 0.3910 / 0.0826。表中 0.19–0.31 的 IoU 对应约 1–2 像素边界误差，不等于"分割质量 30%"，详见[定义对照文档的边界敏感性一节](小目标评价指标_定义与代码对照.md#iou-的边界敏感性seal-gt-实测)。

复算命令（本地，`tqdm` 用 `tmp/stub` 占位，四个指标函数未改动）：

```bash
python tmp/make_blank_maps.py Ours/Seal_test_GT tmp/baseline_blank/maps
python tmp/run_eval_no_tqdm.py tmp/baseline_blank/maps Ours/Seal_test_GT tmp/baseline_blank/metrics.json
```

## 训练不稳定与失败记录

| 方法 | 现象 | 处理 |
|---|---|---|
| DHiF（TCSVT26） | MTU 主干 + SoftIoU/全局 SoftIoU 均退化到全背景，100 epoch val IoU 0.00013 | 记入实验记录，不进入主表 |
| RPCANet（官方设置） | 逐样本 SoftIoU + Adam 5e-4：val IoU 恒 0；5e-4 + 全局 SoftIoU 第 4 epoch 到 0.298 后发散 | 改 dataset 级 SoftIoU + lr 1e-4 后稳定在 0.33，表内为该设置 |
| RPCANet++（官方设置） | 同上 | 同上 |
| UIU-Net | BCE 在第 20 epoch 后退化为全背景 | 取 val 最优（第 20 epoch） |
| ACM | 官方 SoftIoU 不收敛，两个种子均复现 | 负结果存档，不入表 |
| NS-FPN（CVPR26） | 需要编译自定义 MSDeformAttn CUDA 算子，服务器无 nvcc | 未训练 |

## 与弱监督主表的关系

`docs/Seal量化SOTA表.xlsx` 第 3～20 行是跨域泛化（源域训练或公开权重 → Seal test），第 21～28 行是同域全监督（Seal train → Seal test）。两者监督形式、训练数据与难度不同，只能并列说明"全监督参考"，不能与跨域行直接比大小。
