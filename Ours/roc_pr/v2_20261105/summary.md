# Seal test (1,983 images)：ROC / PR 曲线数据

- **pAUC** = FPR ∈ [0, 5.0e-04] 内的梯形面积再除以 5.0e-04，即图中 ROC 的归一化面积；这是主指标。
- **AUC(全范围)** 为 FPR ∈ [0, 1] 的全积分，只作参考：几乎不预测前景的方法（UIU-Net / SCTransNet / ILNet）在 Seal 上反而拿到 0.977 以上，与"S/MAE 被背景主导"是同一类陷阱，不能当排名依据。
- **AP(PR)** 为按 recall 步进积分的 average precision（与 sklearn 同口径：recall=0 处补 (0,1)，t=0 的"全预测为前景"退化点不参与）。
- **Pd@t=128 / Fa@t=128** 取二值图阈值 `pred >= 128`，与八项指标同阈值，但这里仍是像素级 TPR/FPR，不是目标级 Pd/Fa。
